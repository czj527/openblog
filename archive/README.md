# Archive / 历史归档

> 这里存放已否决、已替代或仅供追溯的材料。
> **归档不是当前设计基线。** 不要从本目录复制代码、视觉样式或状态机到新设计/新工程。

## 目录

- [`prototypes/`](./prototypes/)：2026-10-27 被用户否决的 HTML 实验原型、合成 fixture 和验证记录。
- [`legacy-planning/`](./legacy-planning/)：旧 `docs/`、旧 `DECISIONS.md`、旧 `TASKS.md` 的处置说明。旧文件本身不在当前树中，保留在 Git 历史和工作区外受限归档。

## 为什么归档而不是删除

- 保留设计演进证据，避免后续 agent 重复走同一条被否决的路。
- 保留合成 fixture 和验证记录，方便理解当时的契约尝试。
- 旧站材料可能包含不安全的认证示例或敏感信息样式，因此不复制回活动仓库，只保留受限引用。

## 使用规则

1. 归档内容只用于理解历史，不作为需求、设计、技术或验收依据。
2. 不把归档原型中的视觉布局、组件、CSS、JS 或状态机当作默认答案。
3. 不把归档验证结果写成“用户已验收”；内部回归通过不等于用户接受。
4. 不在归档中新增真实个人数据、财务数据、账号或密钥。
5. 如果确实需要引用某个历史结论，先在 `DECISIONS.md` 或 `redesign/_brief/decision-register.md` 中重新登记，并说明为什么仍然有效。
