## 9. 国际化、SEO、分发与变现（证据见 `research/04b-i18n-seo-monetization.md`）

### 9.1 国际化（R8：“不止国内能访问”）

| 议题 | 决策 | 状态 | 理由 |
|---|---|---|---|
| 路由 | zh-CN 在 `/`，en 在 `/en`（`next-intl`，`localePrefix: 'as-needed'`） | 🟢 | 权重集中在一个站、一套部署、hreflang 最简单；Next.js 16 里 `middleware.ts` 已更名 `proxy.ts` |
| 语言协商 | 只对 `/` 做一次 302（`Accept-Language` → 写 Cookie）；**深链永不自动跳转** | 🟢 | Google 明确建议避免按语言/IP 自动跳转，爬虫常不带 `Accept-Language` |
| hreflang | `zh-CN` / `en` / `x-default`（指向 `/en`），互指且含自身，用绝对 URL；只选一种声明方式（建议 sitemap） | 🟢 | 官方规范；混用易出错 |
| slug | **两种语言共用英文语义 slug**（中文标题意译），不可变；`legacySlugs[]` 生成 301 | 🟢 | 中文进 URL 会变成一长串 `%E4…`；文章路径不按语言改，避免配对错乱 |
| RSS | 按语言分：`/rss.xml`、`/en/rss.xml` | 🟢 | 不混语言 |
| 翻译方 | **agent 翻译 + 审核标记**：`translationStatus = machine / reviewed / stale`；源文改动令 `sourceHash` 变化即标 `stale`，只重译差异段 | 🟢 | 不批量铺机翻（Google “scaled content abuse” 针对低价值批量页） |
| **观点类是否翻译** | **默认只翻“解释性/常青类”；观点类要么你审过再发，要么只保留中文** | ❓→🟢默认 | 反讽、语气、立场强度在机翻里最容易失真；agent 翻译时**不得润色立场、保留所有 hedge** |
| 首发范围 | **MVP 只发中文**，但路由、字段、组件从第一天就按 i18n 写；英文在 P2 上线 | 🟢 | 先把中文闭环跑通；i18n 是架构问题，翻译是内容问题 |
| 域名 | 起步可沿用 `czj527.xyz` + `/en`；品牌独立时再评估 `.com`（301 迁移） | ❓待确认（默认建议） | 迁移成本低于现在纠结；域名与备案仍未拍板 |

**字体与排版的中英差异**：拉丁用单一可变 grotesque（subset `latin,latin-ext`，30–60KB）；中文用 `cn-font-split` 切 unicode-range 分片、绝不整包（5–20MB）；中文 17px/1.8，英文 16–18px/1.6；中英混排给拉丁字体单独 family；数字 `tabular-nums`。OG 图也需要中文字体子集（`ImageResponse` 含字体整包 ≤ 500KB），建议**构建期预生成**到 CDN。

### 9.2 SEO 与 AI 爬虫

| 项 | 决策 |
|---|---|
| 三引擎 | Google 与 Bing（IndexNow 一推多引擎）为主；百度可抓境外主机但慢。备案仍未拍板；当前工作假设是先不备案，因此不把百度当目标（若后续备案，可重新评估） |
| 结构化数据 | `BlogPosting`（含 `inLanguage`、`isPartOf` 系列）、`Person`、`BreadcrumbList`；与可见内容一致 |
| OG 图 | 1200×630，**构建期预生成**：标题 + 论点行 + 当季窗景切片 |
| 站内结构 | 系列页（有序目录 + 上下篇 + “第 N / M 篇”）、话题枢纽页、“从这里开始”页；相关文章 = 标签 + 构建期 embedding 取 3–5 篇 |
| 薄页治理 | 搜索结果页、少于 3 篇的标签页、分页第 2 页以后 `noindex,follow`；`lastmod` 只在正文实质变化时更新 |
| CWV 预算 | LCP ≤ 1.8s（上限 2.5s）、INP ≤ 150ms、CLS ≤ 0.05；首页 LCP 元素 = 静态海报；广告位必须预留尺寸（见 4.9） |
| `llms.txt` | **低成本可选**（P2 随 `.md` 端点一起上），**不当排名杠杆**——Google 明确不用，多数 AI 搜索未消费 |
| AI 爬虫策略 | ❓ 推荐默认：**允许检索/引用型**（Googlebot、Bingbot、OAI-SearchBot、PerplexityBot），**拒绝训练型**（GPTBot、ClaudeBot、Google-Extended、CCBot）。`robots.txt` 只是君子协议，不是防护 |

### 9.3 变现：按阶段设门槛，而不是一开始就铺广告

**先说现实**（行业估算，样本自选、地区/品类差 5–10 倍，**只当量级**）：

| 月 PV | 英文 Tier-1 展示广告 | 中文/大陆流量 |
|---|---|---|
| 1 万 | $30–100 | $5–30 |
| 5 万 | $150–500 | $30–150 |
| 10 万 | $300–1,000 | $60–300 |

稳定到 1 万 PV/月通常需要 12–18 个月。**所以：先把站当作“记录 + 作品集”，收入是副产品。**

| 阶段 | 做什么 | 门槛 / 前置 |
|---|---|---|
| P1–P2 | **不放任何广告**；保持阅读体验与 CWV | — |
| P3 | 联盟（技术/书籍/工具类）与整站赞助；个人可用的大陆渠道有限（淘宝客等，CPS 1–30%） | 内容 ≥ 20 篇、有稳定读者 |
| P4 | 评估 AdSense：官方无最低流量，但**审核看“低价值内容”**，建议 15–25 篇长文 + About/Privacy/Terms/Contact + 明确作者再申请 | 英文版已上线；**必须接 Google 认证的 CMP**（EEA/UK/瑞士，免费的 Google CMP 起步）；`ads.txt`；广告位预留尺寸 |
| P4+ | 会员/赞助/数字产品/付费 newsletter | 大陆个人用 Stripe 不友好，可用爱发电/Patreon |

**必须提前写进架构的“商业化触发条件”**：

1. **一旦上广告或其他商业化 → 天气数据源必须升级**：Open-Meteo 免费层**仅限非商业**；届时买商用订阅或换源。所以 `WeatherProvider` 必须是接口（4.3）。
2. AdSense 在大陆**基本不可用**（Google 访问不稳、收款需境外账户），**不能当大陆流量的变现方案**；国内广告联盟（百度联盟等）要求 ICP 备案 + 大陆服务器，与当前“先不备案”的工作假设冲突（备案仍未拍板），**相当于暂时放弃国内广告**——这是合理取舍，但要知道代价。
3. 广告是 CLS 的最大来源之一：只允许出现在文章页、最多 2–3 位（第 2 段后 1 个、文末 1 个）、**首页绝不放**，LCP 之后才加载脚本。

**WordPress 的角色**：你的原文提到“出海独立内容站多用 WordPress”。数据属实（WordPress 占全站 39.6%，w3techs 2026-10-23），原因是**插件生态与“不改代码也能运营”**。但你的运营者是 agent，不是你本人点后台，这个优势对你不成立。自建需要补齐的能力已逐项设计好（见下表），**这是你选择 Git + MDX 的代价清单，不是遗漏**：

| WordPress 里靠插件的能力 | 本方案的自建做法 | 阶段 |
|---|---|---|
| Meta / OG / canonical / sitemap / robots | Next Metadata API + `sitemap.ts` / `robots.ts` | P1 |
| 301 重定向管理 | frontmatter `legacySlugs[]` + 构建期生成 redirect map | P1 |
| 内链推荐 | 构建期标签/embedding 产出 `related` | P2 |
| 媒体库（多尺寸 AVIF/WebP） | 上传 → 构建/边缘生成多尺寸 → CDN；媒体清单入库 | P1 |
| 版本 / 回滚 / 定时发布 | Git（天然）+ `scheduledFor` + 定时构建 | P1 |
| 广告位管理 | 内容块 `adSlot` + 前台组件 + 全局开关 | P4 |
| 表单（联系、订阅） | 自建 API + Turnstile + 邮件通知 | P2 |
| 备份 / 安全 | Git 即备份；托管平台 + 每日导出 | P1 |

**重新评估 WordPress（或 headless WP）的触发条件**：①出现第二个作者/外包编辑；②广告或联盟成为主要收入、且运营需要大量插件级功能；③内容量上千篇、构建时间不可接受且 ISR 也解决不了。在此之前，不动。

### 9.4 分发：文章 → 视频（R8“做成输出视频引流”）

**管线**（P4 才实现，但字段 P1 就预留，见 `DESIGN-BRIEF.md` §5 与未来内容契约）：

```
文章 ─► videoBrief（hook / 6–8 段 / 每段：旁白·屏显字·画面） ─► 分镜 JSON
     ─► HyperFrames HTML 合成 ─► render ─► ffmpeg（混音/响度/字幕/多画幅）
     ─► 16:9（YouTube/B站）+ 9:16（抖音/小红书/视频号）
```

- **配音**：真人 > TTS；TTS 按句生成以便对齐字幕。你本机已有 ffmpeg 与 HyperFrames 相关技能，**工具链基本齐备**。
- **字幕**：竖屏每行 14–18 字、最多 2 行；国内平台烧录，YouTube 用软字幕。
- **封面三画幅**：16:9、3:4（小红书）、9:16（抖音/视频号）。
- **引流的现实**：国内平台普遍**禁止站外链接/二维码/联系方式**（B站、抖音、小红书、视频号规则各异，且每季度会变）；YouTube Shorts 的简介与评论里 URL 不可点。所以**不要把“导流”写进视频本身**，用同名账号 + 评论区置顶关键词 + 主页简介做弱引导；发布前复查规则。
- **首发优先级**（推荐）：YouTube + B站长视频；抖音/小红书做切片。

### 9.5 Newsletter（P4）

| 方案 | 推荐度 | 说明 |
|---|---|---|
| 自建 + Resend/SES（海外名单）+ 国内 ESP（大陆名单） | **推荐** | 成本最低、完全可控；**两条发送通道分开**；退订/退信/合规自理 |
| Ghost 内置 | 备选（你不想维护时） | 博客 + 会员 + 邮件一体，但自托管 bulk 仅支持 Mailgun，且会与 Git 为源的内容流冲突 |
| Buttondown / Beehiiv / Substack | 不优先 | 品牌与数据受制或成本随规模上升 |

大陆邮箱送达现实：Gmail 不可达；QQ/163 对境外批量邮件过滤严。需独立发信子域 + SPF/DKIM/DMARC + 双重确认 + 纯文本 + 低频预热。
