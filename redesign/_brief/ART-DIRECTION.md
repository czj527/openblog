# 首页「窗外」视觉方向（主 agent 定稿 v0）

## 一句话

**一盏很小的暖光，在壮阔而不断变化的世界里。**
这是「一个普通人 × 一场巨大浪潮」的视觉隐喻，也直接对应「个人小窝」。首页 = 一扇窗，窗外是真实的季节、天气与时间。

情绪：安静的敬畏、沉思、克制的希望——不是忧郁，也不是炫技。壮阔而温柔。

## 硬性规则（底图，所有方向通用）

1. **摄影级写实 + 克制的电影感**：自然光物理、大气透视、真实镜头特征（35–50mm 等效、柔和高光滚降、极轻的胶片颗粒）。
   **不是插画、不是 3D 渲染、不是动漫、不是概念原画。**
2. **16:9 构图**：地平线落在下 1/3，或层叠山脊；
   画面**上方—中部**（约 40% 宽 × 30–60% 高）是「留白带」：低细节、低对比（天空 / 雾 / 水面），用于放导航与按钮；
   画面**底部 12%** 偏暗，用于状态文字。
3. **焦点**：画面下部三分点附近有一间**极小**的小屋（面积 ≤ 画面 2%），其中**一扇亮着暖光的窗**是全画面唯一的人造暖光源。
   **无人、无车、无文字、无 logo、无水印、无建筑群。**
4. **同一场景全年复用**（同取景、同小屋、同湖谷）：用前景乔木（开花 → 浓绿 → 琥珀红 → 光秃/覆雪）、山体积雪、水面状态来表达季节。
5. **色彩**：自然色彩科学，克制饱和。每季主色倾向：
   - 春：冷调晨光、淡绿、白粉花、薄雾
   - 夏：深邃自然蓝、金色高光、积雨云
   - 秋：琥珀 / 赭石 / 铜红、低角度暖光、暖雾
   - 冬：钢蓝、雪白、石墨岩；**唯一暖色 = 小屋窗光**
6. **「干净底图」原则**：天气粒子（雨丝、雪花、落叶）由前端着色器叠加。
   雨天底图 = 阴、湿、雾、低云、水面反光；雪天底图 = 积雪、阴天、柔光；**不要画出密集的雨丝/雪花**。
7. **AI 味黑名单**（出现即重来）：霓虹/赛博、紫粉渐变天空、过饱和的「AI 日落」、悬浮岛/奇幻元素、发光蘑菇/发光植物、
   正中对称的小路、过度光晕与镜头光斑、塑料般过度平滑的质感、HDR 光晕、动漫笔触、可读的假文字、画面正中的「主角」。

## 方向对照（本轮出图用于对比）

| 方向 | 场景 | 说明 |
|---|---|---|
| **A（主推）山湖谷地** | 俯视一片安静的山谷，湖或河蜿蜒，湖畔草甸上一间小木屋 + 一个小栈桥，远处层叠山脊 | 四季差异最强，天气最容易叠加，最像「高清动态壁纸」，且「小屋暖窗」的叙事最完整 |
| **B 城市边缘** | 从中层住宅窗台/阳台望出去：江边的普通城市（桥、树、远山），傍晚万家灯火中的一盏窗，非摩天楼天际线 | 更贴近「出租屋窗外的普通人」；风险：容易滑向赛博/霓虹，需严格克制 |
| **C 纯粹天空** | 只有天空与光：云的形态、季节色光，近乎抽象的极简摄影，可有极小的鸟或没有主体 | 最利于文字可读与首页「空荡」感；季节辨识度弱，需靠粒子与调色补足 |

## 变体矩阵（方向 A 要出的图）

- **四季 × 白天（4 张，作为基础集）**：春日、夏日、秋日、冬日（晴/少云，光线好看的时段）
- **时段与天气代表作（6 张）**：
  春·薄雾黎明 ｜ 夏·傍晚积雨云（雷雨前） ｜ 夏·晴夜星空（银河/满月，窗光唯一暖光）｜
  秋·阴雨清晨（湿、雾、水面反光） ｜ 冬·大雪后的阴天 ｜ 冬·雪夜（窗光映雪）
- 方向 B：3 张（秋·傍晚晴、雨夜、冬·清晨）；方向 C：2 张（秋·金色时刻天空、冬·冷调天空）。

一致性策略：先出基础集里最好的一张，再用图像编辑接口（`/v1/images/edits`，以基础图作参考）生成其余季节/时段，
保持取景、小屋、山体、湖面形态不变；若编辑结果构图漂移严重，退回纯文生图并用更严格的构图描述。

## 技术规格

- 母版：3840×2160（16:9），存到 `D:\openblog\_assets\masters\`（**不进仓库**）。
  编辑接口单图 ≤ 25MB，母版建议 `output_format: jpeg`, `output_compression: 95`。
- 仓库内保留 Web 优化版（`redesign/concepts/`）：2560 宽 WebP（质量约 82）+ 640 宽缩略图；文件名 `A-spring-day.webp` 这类可读命名。
- 探索阶段可用 2048×1152、quality=`high` 控成本/耗时；定稿用 3840×2160。
- 每张图必须**亲自查看**（用 Read 工具读图）并按「硬性规则」逐条打勾；不合格就改提示词重来（每张最多重试 3 次）。
- 提示词写法：英文，按 [镜头/光线/时间/季节/天气/构图/小屋/前景/色彩/质感/禁止项] 组织；写明「photographic, natural light, subtle film grain, no text, no people, no vehicles」。

## 与前端的关系（供原型参考）

- 前端着色器叠加：窗玻璃雨滴、降雨/降雪粒子、雾层、云影、落叶/花瓣/萤火虫、轻微视差；底图按 (season, timeOfDay) 选取并交叉淡化。
- 液态玻璃按钮是「窗玻璃上的物件」，不是装饰：折射/高光应取自背后的底图。
- 文字在亮底图（雪、晴空）上的可读性靠：顶部/底部极轻的渐隐、按钮自带对比、必要时按底图亮度自动切换前景色。
